

# 🏆 Achievement System

The achievement system is designed to encourage challenge runs, mastery, and weapon specialization.  
It should reinforce replayability and create long-term engagement goals.

## 🎯 Core Achievements

### Weapon Challenge Runs

- [ ] Finish a run using only **Shotgun**
- [ ] Finish a run using only **Pistol**
- [ ] Finish a run using only **Saw**

### Restriction-Based Challenges

- [ ] Finish a run without picking up any heal
- [ ] Finish a run under 10 minutes

### Weapon Mastery

- [ ] Evolve Shotgun to **Mythic**
- [ ] Evolve Pistol to **Mythic**
- [ ] Evolve Saw to **Mythic**
