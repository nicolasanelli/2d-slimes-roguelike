# 2D Slimes Roguelike

A 2D top-down roguelike game built with Godot, focused on procedural progression, combat systems, and scalable game architecture.

This project explores modular gameplay systems, enemy behavior patterns, and progression mechanics while maintaining clean and extensible architecture.

---

## 🎮 Overview

2D Slimes Roguelike is a top-down action roguelike where the player fights waves of evolving slime enemies in progressively harder encounters.

The project focuses on:

- Modular gameplay systems
- Scalable enemy behavior
- Upgrade and progression systems
- Performance optimization for multiple entities
- Clean scene and node architecture in Godot

## 🏗 Architecture

The project follows a modular structure to keep gameplay systems decoupled and extensible.

Main architectural concerns:

- Separation between gameplay logic and visual representation
- Reusable components
- Centralized managers (e.g., drop manager, wave manager)
- Scalable stat calculation
- Clean node hierarchy organization
